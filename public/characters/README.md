# Character art

Drop the official LUNITA character artwork here, one file per character. The game tries
.png, then .webp, .jpg and .jpeg for each name:

lumi, elowen, cinder, pip, seren, quill, marigold, fennel, oriel, nox

Example: public/characters/lumi.png

The artwork is displayed as-is (never redrawn or restyled). To change a path or add a character,
edit `image` in src/characters/roster/<id>.ts.
